# TEIKA Web v1.0

منصة ويب موحدة لتوصيل الطعام في الخرطوم، السودان، بدون تطبيقات Android.

## الواجهات
- `/` العميل
- `/restaurant` المطعم
- `/captain` الكابتن
- `/admin` لوحة التحكم

## التشغيل
يتطلب Node.js 18 أو أحدث.

```bash
npm start
```
ثم افتح `http://localhost:8080`.

## قواعد العمل
- الدفع: كاش فقط
- عمولة المطعم: 12%
- الكابتن: Freelancer
- المدينة: Khartoum, Sudan
